# Security policy

## Supported versions

This fork has not published a versioned release yet. Security fixes are made on
the `main` branch; the historical XMMS 1.2.x releases are unsupported.

GTK2 itself is end-of-life. Reports that only demonstrate an issue in an
unmodified GTK2 dependency should be directed to the relevant distribution.
Reports involving how XMMS uses GTK2 or processes media, playlists, skins,
plugins, or network streams are in scope.

## Reporting a vulnerability

Please do not publish exploit details in a GitHub issue.

Use a private contact method listed by the
[maintainer](https://github.com/tuunanet). If no private method is available,
open a minimal issue asking the maintainer to establish private contact; include
no technical details until a private channel is agreed.

Include, when possible:

- the affected code and configuration;
- steps or a proof of concept that reproduces the issue;
- expected impact;
- tested operating system and compiler; and
- any proposed mitigation.

The maintainer will acknowledge the report, assess impact, and coordinate a fix
and disclosure timeline. Please allow reasonable time for a fix before public
disclosure.
